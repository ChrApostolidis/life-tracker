Backend

Where your Life Tracker API is reachable from this machine, for example http://localhost:8080. Any path is dropped. Saving asks Chrome for permission to call that host.

Account

The Life Tracker password set on the server. It is sent once to start a session, and only that session is kept, never the password.

Logged in. The session lasts 30 days and renews whenever the extension talks to the server.

Microphone

Chrome cannot show the microphone prompt inside the popup or the side panel, so voice capture needs permission granted once here. Only the transcribed text is ever saved, never audio.
